# State of Decay 2 Maps

Четыре отдельных региона по мотивам State of Decay 2. Ручная реконструкция,
без импорта игровых ассетов.

## Карты

**Meagher Valley** — фермерская долина, Whitney Field, Camp Kelenqua,
Mazzara Farm, Squelones Brewing, Sasser Regional Hospital.

**Drucker County** — пустынный округ, Mike's Concrete, Barricaded Strip Mall,
Knights Drive-In, Wheelhouse Truck Stop, Lundegaard Mansion.

**Cascade Hills** — холмы и мосты, Container Fort, Bridge Fort,
Church on the Hill, Corner Office, Cash Beaumont's.

## Размер

```text
4 карты
2880 клеток
Trumbull 930 + три региона по 650
5 баз/достопримечательностей на карту
```

## Требование

Нужен базовый мод:

```text
KnoxMap OMSK EXPANSION
```

SoD2-пак ставится отдельным item и включается вместе с ним. Новый save
обязателен.

## Важно

Это ручные планировки зданий и баз, а не копирование карт из State of Decay 2.
Визуал, двери, ворота и крышный доступ могут требовать доработки.
